# Module 10 Reflection

In this module, I learned how to use mobile device features in a React Native app with Expo. I learned how to use the camera to take pictures and how to request permission before using the camera. I also learned how to use GPS to get the current latitude and longitude.

One thing I learned is that permissions are important because the app needs the user's approval before accessing private device features. I also learned how to handle situations when a user denies permission or something goes wrong.

Another important part of this project was saving the journal entries. I used AsyncStorage to save the entry information and the file system to store the pictures. This allowed my app to keep the saved entries even after I closed and reopened it.

Overall, this module helped me understand how mobile apps work with device features. I also got more practice using TypeScript, Expo packages, and testing an app on an Android emulator. I enjoyed seeing the different features work together in one project.
