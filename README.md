## Module 9 - NFL Teams and Players

### What I Learned

In this module, I learned how to add a new feature to an existing React Native application without affecting the features I had already built. I created an NFL section where users can browse teams, search for teams, view team details, and see sample players. I also added the ability to save favorite teams and remove them from the favorites list.

One important part of this assignment was using AsyncStorage to save favorite teams. This allows the favorites to remain saved even after closing and restarting the application. I also learned more about navigation between screens and passing information from one screen to another.

I tested the application using the Android emulator and confirmed that the NFL screens, search, team details, and favorites were working. I also checked that favorite teams remained saved after restarting the app.

Overall, this module helped me understand how to add new functionality to a React Native application, work with local data storage, and organize navigation between multiple screens.
